## Install

1. Download `DSH_Box_1.12.35_patched.apk`.
2. If the phone still has the original DSHBOX-signed app, uninstall it first. That wipes the app data. A previous debug build (1.12.34) can update in place.
3. Open the APK and allow install from this source.
4. In the app, Stop, then Start DSH Web, so the new search plugin loads.

This build includes the config crash-loop fix and the web search fix.
